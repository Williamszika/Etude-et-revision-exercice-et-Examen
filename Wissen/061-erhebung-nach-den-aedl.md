# Erhebung nach den AEDL

## Quelle: PDFs/62-erhebung-abedl.pdf

## Dokumenttyp
Pflegedokumentations-Formular / Erhebungsbogen (Assessment-Formular) zur strukturierten Pflegeanamnese nach dem AEDL-Modell (Aktivitäten und existentielle Erfahrungen des Lebens). Ankreuz- und Ausfüllformular über 2 Seiten. Herausgeber laut Kopfzeile: PROVIDER Pflegedokumentationssysteme GmbH (Postfach 22 24 60, 57340 Sörgen), "Pflegedokumentation nach den AEDL – Pflegeprozessplanung nach personellem Bedarf", 4. veränderte Auflage 2007. Formular-Nr. 2132. Fußzeile: "Erhebung nach den AEDL".

## Inhalt (nach Abschnitten)

### Kopf / Formularlogik
- Personalfeld oben: **Vor-/Nachname** des Bewohners/Klienten.
- **Legende der Hilfe-Kürzel** (in die Kästchen "Hilfe" einzutragen):
  - **A** = Anleitung
  - **B** = Beaufsichtigung
  - **U** = Unterstützung
  - **TU** = teilweise Übernahme
  - **VÜ** = vollständige Übernahme
  - Hinweis: "(entsprechende Kürzel in Kästchen Hilfe eintragen)".
- Rechte Spalte durchgehend: Kästchen-Spalte **"Hilfe"** zur Eintragung des Selbstständigkeitsgrades je Aktivität.
- Wiederkehrende Bewertungsskala je Merkmal: **selbstständig / bedingt selbstständig / teilweise unselbstständig / unselbstständig**, dazu Freitextfeld **"Bemerkungen"**.
- Jede AEDL-Kategorie enthält Zeilen für **ergänzend:**, **Pflegediagnosen:** und **Hilfsmittel:**.

### AEDL 1 – Kommunizieren können
- **Hörvermögen:** ungestört / eingeschränkt / mäßig / schwer / Ausfall.
- **Sehvermögen:** ungestört / mäßig / schwer / Ausfall.
- **Sprache ist:** offen, direkt, verständlich, unverständlich, umständlich, leise, laut, verwaschen, nuschelnd, stotternd; zitternd, monoton, klagend, hastig, lebhaft, ängstlich, unbewegt, aphatisch.
- **Körpersprache / Mimik ist:** heiter, gelassen, entspannt, in sich ruhend, unterwürfig.
- **Muttersprache ist / spricht deutsch:** fließend, gebrochen, spricht Dialekt.
- **spricht:** gerne / nicht gerne / viel / wenig; **spricht fällt:** leicht / schwer.
- **Sprachvermögen ist:** groß / mittel / gering.
- **Hilfsmittel:** Brille, Hörgerät rechts, Hörgerät links.
- **Pflegediagnosen:** Beeinträchtigte verbale Kommunikation, Beeinträchtigte Sozialinteraktion, Beeinträchtigtes Hörvermögen, Beeinträchtigtes Sehvermögen, Behandlungsempfehlung.
- **Wahrnehmungsstörung:** visuell, auditiv, kinästhetisch, taktil, olfaktorisch, Neglect.

- **hochgradige Spastik:** nein / ja.
- **Thrombose:** nein / ja.
- **Akinese, Tremor, Paresen, Plegien; Hemiplegie.**
- **Kontraktur an:** nein / ja.
- **Dekubitus:** nein / ja; Dekubitusschaden.
- **Hilfsmittel:** Gehstock, Rollator, Rollstuhl, Gehbock.
- **Bewegungsgrad / Bewegungsausmaß.**
- **Gangart:** langsam, kraftlos, schlurfend, trippelnd, unsicher, vorsichtig, kleinschrittig, ataktisch; stolz, gerade, steif, aufrecht, krumm, gebeugt, erschöpft.
- **Pflegediagnosen:** Beeinträchtigte Mobilität, Beeinträchtigte Transferfähigkeit.
- **Psychischer Zustand** (innere Ruhe und Gleichgewicht, Angst, Zorn, Erregung … und Gewohnheiten).
- **Sturzrisikoerkennung / Kontrakturrisikoerfassung.**

### AEDL 3 – Vitale Funktionen aufrechterhalten
- **Atemfrequenz:** Eupnoe, Tachypnoe, Bradypnoe, Apnoe; Atemrhythmus.
- **Atemgeräusche:** nein, feuchend/pfeifend, röchelnd, rasselnd, geräuschvoll.

- **Atemskala / Körpertemperatur / Veränderungsgefahr / Sauerstoffversorgung.**
- **Pflegediagnosen:** Beeinträchtigte Atmung, Verminderte Herzleistung; Durchblutungsgefahr gastrointestinal / kardiopulmonal / peripher.
- **Hautfarbe:** normal trocken, abnorm trocken, feucht, gerötet, blass, gelb-braun, blau-grau, bläulich-rot; Pigmentmangel, Pigmentierung.

### AEDL 5 – Essen und Trinken können

- **Hilfsmittel:** PEG.
- **enterale Ernährung, orale Ernährung, mundgerechte Zubereitung, Einfuhrprotokoll, Schluckstörungen.**
- **Trinken:** ausreichend, viel, wenig; **Trinkm.:** ansehen, ohne Hilfe.

### AEDL 6 – Ausscheiden können

## Kernbegriffe (Glossar)
- **AEDL:** Aktivitäten und existentielle Erfahrungen des Lebens – Pflegemodell (nach Monika Krohwinkel) mit 13 Kategorien; Grundlage der strukturierten Pflegeanamnese.
- **Hilfe-Kürzel A/B/U/TU/VÜ:** Anleitung, Beaufsichtigung, Unterstützung, teilweise Übernahme, vollständige Übernahme – abgestufte Grade des Pflegeaufwands je Aktivität.
- **Selbstständigkeitsskala:** selbstständig / bedingt selbstständig / teilweise unselbstständig / unselbstständig.
- **Pflegediagnose:** standardisierte Benennung eines pflegerischen Problems/Risikos (je AEDL zugeordnet).
- **Kontinenzprofile:** sechsstufige Einordnung der Ausscheidungskompetenz (von Kontinenz bis nicht kompensierte Inkontinenz) nach Expertenstandard Kontinenzförderung.
- **Dekubitus / Sturzrisiko / Kontrakturrisiko / Mangelernährung (BMI):** integrierte Risiko-Assessments nach den Expertenstandards.
- **Eupnoe / Tachypnoe / Bradypnoe / Apnoe:** normale / beschleunigte / verlangsamte / aussetzende Atmung.
- **Tachykardie / Bradykardie / Arrhythmie:** zu schnelle / zu langsame / unregelmäßige Herzaktion.
- **Hypertonie / Hypotonie:** hoher / niedriger Blutdruck.
- **Zyanose:** bläuliche Verfärbung (Lippen, Fingernägel, Haut) bei Sauerstoffmangel.
- **Spastik / Akinese / Tremor / Paresen / Plegien / Hemiplegie:** Bewegungsstörungen (Verkrampfung / Bewegungsarmut / Zittern / Teillähmung / Lähmung / halbseitige Lähmung).
- **Kontraktur:** dauerhafte Bewegungseinschränkung eines Gelenks.
- **Neglect:** Vernachlässigung einer Körper-/Raumhälfte (Wahrnehmungsstörung).
- **PEG:** perkutane endoskopische Gastrostomie – Sonde zur enteralen Ernährung.
- **Kachektisch / adipös:** stark abgemagert / stark übergewichtig.
- **Obstipation / Diarrhö:** Verstopfung / Durchfall.
- **Anus praeter / Stomabeutel / Kondomurinal / suprapubischer Katheter:** Hilfsmittel der Ausscheidungsversorgung.
- **Freiheitsentziehende Maßnahmen:** genehmigungspflichtige bewegungseinschränkende Maßnahmen.
- **Biografiearbeit / Erstgespräch:** Erhebung existentieller Erfahrungen; Erstgesprächs-Informationen werden farblich gekennzeichnet.
