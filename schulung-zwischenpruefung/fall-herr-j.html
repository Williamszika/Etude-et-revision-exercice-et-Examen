    PE(S)R schreiben — ein Problem pro Tag

    3 Tage × 30–40 Minuten

    Le cœur de l'examen. Un seul problème par jour, mais complet.

    So gehst du vor

    1. Lis d'abord le modèle complet (Gefahr einer Harnwegsinfektion) et regarde comment chaque ligne est construite.
    2. Jour 1 : Körperpflege und Ankleiden · Jour 2 : Stuhlinkontinenz und Haut · Jour 3 : Blutzucker.
    3. Écris dans cet ordre : P → E → (S) → R → Nahziel → Fernziel → Maßnahmen → Begründung.
    4. Relis avec la liste « Geschafft, wenn » ci-dessous, puis envoie-le-moi avec 📤.

    Geschafft, wenn …

    • P : „Herr J. kann … nicht …“ ou „Gefahr einer …“ — pas un nom de maladie
    • S seulement pour un problème aktuell ; pour un potentiell : les facteurs de risque
    • R : ce qu'il peut encore faire — et la Hilfeform correspond à cette ressource (pas de vollständige Übernahme pour ce qu'il sait faire)
    • Ziel SMART : qui, quoi, comment on le mesure, jusqu'à quand
    • chaque Maßnahme répond aux W-Fragen : Wer? Was? Wie/womit? Wann? Wie oft?
    • Begründung : au moins un Expertenstandard, un diagnostic ou un médicament
    → PE(S)R
